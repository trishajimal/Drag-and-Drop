# Drag and Drop

A small browser-based drag-and-drop demo built with HTML, CSS, and vanilla JavaScript. Drag any list item between the two dashed boxes.

## Run the project

No installation or build step is required:

1. Download or clone this repository.
2. Open `index.html` in a web browser.
3. Drag an item from one box to the other.

## Project files

- `index.html` — page markup and the four draggable list items.
- `style.css` — layout, colors, and typography.
- `script.js` — drag-and-drop behavior for the two boxes.
- `icon.png` — small icon shown alongside each item.

The page loads Poppins from Google Fonts. If the font cannot be loaded, it falls back to a sans-serif font.
